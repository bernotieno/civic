📋 Technical Notes

🔧 Setup Requirements

  • ✅ PostgreSQL with md5 authentication for 127.0.0.1
  • ✅ Run python manage.py migrate for database setup
  • ✅ Populate data with python manage.py setup_counties
  • ✅ Secure endpoints with @invisible_permission_required decorator

🛡️ Security Considerations

  • JWT authentication for all protected endpoints
  • Role-based access control enforcement
  • Rate limiting on submission endpoints
  • Anonymous session management and cleanup
  • Audit logging for administrative actions
